# Instruções de execução

## Google Colab

1. Abra o arquivo `MiniProjeto_LaraHassen_T3.ipynb` no Google Colab.
2. Selecione `Ambiente de execução > Executar tudo`.
3. Aguarde o carregamento, o tratamento e a análise dos dados.
4. Execute a última célula somente se desejar baixar novamente o arquivo `Varejo_limpo.csv`.
